# Example one-page websites

Five labelled examples of the kind of one-page site NewCo Studio builds. Each page is a static `index.html`, self-contained, with no tracking, cookies, or external scripts. Every page shows this banner:

**Example website by NewCo Studio — not a real business**

They use fictional generic names, placeholder contact lines (“Your phone number”, “Your email address”, “Your town”), and sample prices marked as samples. There are no reviews, ratings, or opening hours presented as real. Images are original SVG. See [CREDITS.md](CREDITS.md).

Each page has `<meta name="robots" content="noindex">`. `robots.txt` also disallows `/_demos/`.
